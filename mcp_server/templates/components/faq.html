Solver-MCPs

AI-driven Solver-MCP. Submit CFD, MD, and FEM jobs in natural language — results appear inline.

⚗

What isSolver-MCP?

Solver-MCP is an MCP (Model Context Protocol) server that connects an AI agent to three Solver-MCP solvers. An engineer describes a simulation in natural language. The agent validates the request, runs the solver in an isolated Docker container, and returns structured results. CalculiX is already connected to AMS's Solver-MCP platform.Solver-MCP adds OpenFOAM, LAMMPS, and FreeCAD.

🔬

What can each solver do?

⚡
OpenFOAM
Simulates how fluids flow through a geometry by solving the Navier-Stokes equations over a mesh. This connector runs simpleFoam for steady-state, turbulent, incompressible flow and returns pressure and velocity field summaries. Visualise results with ParaView.
⚛
LAMMPS
Models the motion of individual atoms under an interatomic potential. This connector runs NVT ensemble simulations of a Lennard-Jones fluid in reduced units and returns the thermodynamic trajectory — temperature, pressure, and energy over time.
📐
FreeCAD
Performs structural finite-element analysis — computing displacement and stress in solid parts under load. The connector is registered and input is validated, but execution returns NOT_IMPLEMENTED in the Prototype. Full headless FEM is on the Production roadmap.
🚀

How do I submit a simulation?

  1. Select a solver from the sidebar on the left.
  2. The agent introduces itself and tells you exactly what parameters it needs for that solver.
  3. Describe your simulation in the chat. The agent asks for any missing values.
  4. The agent submits the job, polls for completion, and presents results inline in the conversation.
  5. Completed results and their metrics appear inline in the chat and in the result panel, with a full trajectory or field chart and a raw-JSON view.
